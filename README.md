# mark-skills

收集我平时使用 AI 时积累下来的能力与工作流程，沉淀为可复用的 Agent Skill，方便在不同项目里直接调用。

当前积累的 skill，主要是做需求开发过程中提炼的内容。后续会不断完善、壮大、扩展。

## Skills

### req-to-spec

将用户描述的需求转化为类 SDD（Spec-Driven Document）文档。

输入可以是口头描述、访谈记录、聊天摘录、旧系统资料等原始材料；输出两份职责分明、的需求文档：

| 文档 | 内容 |
| --- | --- |
| 总需求文档 | 做什么、为什么做、做到什么程度：背景、范围、核心流程、模块职责、功能清单 |
| 详细需求文档 | 每个功能具体怎么用、系统怎么校验：字段、操作步骤、规则、示例 |

文档会覆盖：

- **整体目录架构**：模块划分与职责边界
- **功能模块**：各模块在流程中的位置与使用角色
- **具体功能拆分**：带编号的功能清单（如 `M1-F01`），并在详细需求中逐条展开

核心原则：**只整理，不发明**。没有来源的内容会标为「待确认」，或先向用户确认后再写入。
